# Chart Viz Pro: Advanced Data Visualization Dashboard

---

The Chart Viz Pro dashboard integrates multi-dimensional data—including election results, wastewater surveillance, and air quality metrics—into a high-end, interactive showcase. It demonstrates advanced technical proficiency in **D3.js** and **Apache ECharts** within a modern **Next.js** architecture.

## ✨ Key Features
- **Pathogen Surveillance**: Real-time tracking of SARS-CoV-2, Influenza, and RSV.
- **Genomic Evolution**: Custom D3.js area charts for variant prevalence waves.
- **Environmental Monitoring**: AQI Candlestick charts and Temporal Detection matrices.
- **Lab Metrics**: Laboratory pipeline throughput (Funnel) and data flow (Sankey).
- **Interactive Filtering**: Selecting a pathogen in one chart automatically filters related visuals (e.g., Radar profiles) across the page.
- **Glassmorphism UI**: A premium, dark-mode medical aesthetic.

## 🛠️ Tech Stack
- **Framework**: Next.js 15+ (App Router, TypeScript)
- **Visualization**: D3.js & Apache ECharts
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: Lucide-react

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd ChartsDemo
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔬 Technical Implementation
- **Bespoke D3 Components**: Used for hierarchical treemaps and regression scatter plots.
- **High-Performance ECharts**: Used for canvas-rendered heatmaps and complex synchronized series.
- **Strict TypeScript**: Ensures data integrity for all scientific data models.
